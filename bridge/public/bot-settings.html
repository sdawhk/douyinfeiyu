VOICE REPLY

语音回复概率

语音服务选择“按概率回复”后，普通聊天按此概率发送语音。

AZURE SPEECH

语音回复

可先保存音色和回复策略；填入 Azure Speech Key 后启用合成。

语音通过 QQ 语音消息发送；Azure 输出 TrueSilk 格式。若 Key 未配置、请求失败或 Azure 不可用，机器人会回退发送文字。群聊自动语音可能增加刷屏和调用费用。
XFYUN SPEECH

讯飞语音合成

使用讯飞开放平台“超拟人语音合成”的凭据；Spark-X2.6 的 MaaS 对话 Key 不适用。

讯飞使用 MP3 合成，NapCat 会转换为 QQ 语音。若讯飞未配置或合成失败，机器人会回退发送文字。讯飞与 Azure 同时开启时优先使用讯飞。
先保存凭据，再点击测试；不会发送 QQ 消息。
EDGE TTS

Edge TTS 朗读

接入 wangwangit/tts 的 Edge TTS 接口，发送普通 QQ 语音；这是朗读，不会唱歌。

先保存地址与音色；测试不会发 QQ 消息。
LOCAL VOICE CLONE

克隆音色

使用本机 GPT-SoVITS api_v2，以一段固定参考音频合成机器人的 QQ 语音。

先保存设置再试听；不会发送 QQ 消息。

先保存语音服务与 RVC 设置；只试听，不发 QQ 消息。
SINGING

歌曲点唱与原创唱歌

现成歌曲由本机搜歌并转换流萤音色；原创歌曲另用 Mureka 生成。

先运行本机点唱依赖安装脚本。发送“歌单”后 5 分钟内可直接回复序号点歌一次，也可随时用“点歌1”播放已有的 60 秒成品；听后说“发整首”才分段制作整首。30 秒试听及红包额度已关闭。所有人可发送“搜歌 歌名”查看候选；主人和新歌白名单 QQ 可用“翻唱 歌名 #2”选择第 2 个结果。
发送“/原创唱歌 海边的夏天”才会调用 Mureka 生成原创歌曲。每次只生成 1 首；页面测试也会产生一次生成费用。
MESSAGE BATCH

连续消息合并

同一人在同一会话连续发言时，收齐后只调用一次聊天模型。

GROUP AFFINITY

群好感度与退群

明确感谢或夸奖会加分，明确辱骂及常见谐音辱骂会扣分；角色雷点不扣分。

明确对机器人感谢或夸奖时，所在群加 1 分；同一人每 20 分钟最多加 1 分、每天最多加 3 分。辱骂最多每 20 分钟扣 1 分；主人和保护群不会因辱骂扣群分。

02

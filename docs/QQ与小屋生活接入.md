# QQ 与小屋生活接入

2026-11-21：大肥鱼的主要生活场景是 QQ 和小屋世界。本次将小屋中真实完成的经历接入现有 QQ 人格、主动联系和日记链路。

## 实际接入方式

没有直接安装桌面的“活人感插件包”。包内 `dsh-dafeiyu-life` 主要围绕 B站运行，`dafeiyu-console` 依赖另一套本机核心，`dsh-dafeiyu-emotion` 主要处理桌面录音。当前 QQ 人格层已经负责情绪、关系、偏好和未收尾话题，因此补充共用生活事实层，不再启动另一套 B站人格、情绪或记忆系统。

实现位于 `bridge/src/companion-life.mjs`。只读小屋桥已经生成的 `cabin-log.jsonl`，不新增游戏动作、网络请求、模型轮询或消息发送计时器。小屋仍按原有自主活动设置生活。

- 普通 QQ 回复通过 `buildPersonaContext` 读取生活经历。主人私聊可自然带起最近六小时的事；群聊和其他私聊只在相关话题出现时读取大肥鱼自己的小屋经历。
- 二代工具会话的 `qq_get_prompt` 返回 `life` 字段；唤醒上下文也按当前话题补入经历。
- 既有主人主动联系评估增加最近六小时的小屋事实来源。原开关、安静时段、冷却、每日上限保持有效；同一来源不重复使用，同一种活动在二十四小时内不重复作为主动话头。
- 日记素材增加当天、上次写入时间之后的小屋活动。按不同动作合并，维护 `used.cabinAt` 去重，原字数、频率、预算和隐私规则继续生效。游戏中的日记面板仍读取原日记目录。

## 事实与隐私边界

只取匹配当前住户的已完成动作；旧版无 `status` 的记录来自游戏 `chat-link` 的 `task.status=done` 分支。忽略失败、未完成、未来、重复、损坏、缺少住户归属和疑似指令文本。最多读取日志末尾 256 KiB，聊天回忆默认看近三十天、每次最多三种活动。游戏日志本身仍按原先四百行上限保存，不额外复制成长久档案。

每条经历保留日期，今天、昨天、前天按新加坡时间区分。游戏经历不能说成现实身体活动，历史反馈不能直接当作当前情绪，重复执行也不能当作已形成偏好。只读游戏反馈，不自动修改现有人设或情绪状态。QQ 私聊和各群的关系记忆仍由原有作用域隔离；小屋事实层不读取 QQ 私聊内容。

## 路径、回退与验证

与小屋 MCP 使用相同路径：优先 `CABIN_LOG_JSONL`；否则取 `CABIN_BRIDGE_JSON` 所在目录的 `world/cabin-log.jsonl`。默认发现文件位于当前用户桌面 `小屋世界-v0.1/data/bridge.json`。住户优先 `CABIN_RESIDENT`，其次发现文件的 `resident`，默认 `xiaojingyu`。文件不可用时返回无记录，不影响聊天主链路。

在运行环境设置 `DAFEIYU_LIFE_ENABLED=0` 并重启 QQ 服务可关闭本次生活注入、主动话头和日记素材；游戏本身不受影响。改动前源码备份在 `D:/deepseek/backups/qq-cabin-life-20261121-092403`，其中保存的是包含原有未提交改动的当时版本，不能用 Git 的旧版覆盖用户其他修改。

相关验证：`node --test bridge/tests/companion-life.test.mjs bridge/tests/persona-runtime.test.mjs bridge/tests/diary.test.mjs bridge/tests/mcp-cabin-world-safe.test.mjs bridge/tests/persona-maintenance.test.mjs`。测试使用临时游戏日志和模拟 MCP 服务，不向 QQ 发送测试消息。

本机验收：上述 73 项测试全部通过，相关源码语法检查通过。QQ 主服务与工具服务已由原守护程序重启，QQ 和 DSH 连接恢复；工具服务的会话提示接口已返回新增 `life` 字段。只读实测识别到 222 条有效小屋记录，当天日记事实包含购买/食用冰棍、回小屋和闻花。未代用户向 QQ 发送测试消息，表达自然程度仍需日常对话观察。

# 戳一戳动态回应与群聊互怼

2026-11-21：QQ 主桥接的戳一戳回复从随机台词改为当前对话模型生成，增强普通群聊中的吐槽、反讽和回嘴。

## 戳一戳

`bridge/src/poke-interaction.mjs` 将通知描述为真实事件，不伪造群友的文字发言。`qq-bot.mjs` 在现有聊天队列中调用同一个人的会话，并提供本群近期对话、角色、人际关系和当前状态，由模型选择自然回应或沉默。历史配置中的 `replies` / `othersReplies` 字段保留兼容，但运行时不再随机挑选其中的台词。

保留原开关、群聊/私聊范围、是否回应旁人互戳、冷却、每小时上限和连续两次回戳规则。同一聊天有一次生成在途时不重复生成；模型失败也计入频率限制，避免被反复戳出请求风暴。生成前和发送前都会检查允许范围、禁言和回复开关，超过九十秒的反应作废。失败、沉默、无效输出不会回退到固定回答。

戳一戳作为事件交给模型，不注入本轮工具令牌，不当成新任务授权，也不从合成提示里调整好感度、提取人格或关系记忆。最终回应走普通回复的过滤与发送链路；发送成功后才把简短事件标记及回答记入当前会话。旁人互戳不会被误认为在挑衅机器人。

## 群聊表达

`bridge/src/group-banter.mjs` 提供共同规则，接入群友角色卡加载和每轮群聊提示。对明确找茬、互怼邀请，可贴着当前言行损回去、表达不爽，允许口语粗话，不再默认认输、劝和或等到被反复辱骂才有反应。不是按关键词返回骂人语录。

认真求助和事实纠正优先处理；转述他人的辱骂不触发回嘴提示；明确说停止时收住。互怼限于当前话题和回合，不编造现实经历、牵扯家人或隐私、威胁、攻击身份群体、组织围攻或跨群追骂。没有新增攻击对象名单、追骂计时器或自动群发功能，主人私聊人格保持原有规则。

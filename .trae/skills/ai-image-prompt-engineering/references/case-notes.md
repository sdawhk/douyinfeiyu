## 1. 预算与逐层偏移（修前）

- 正向总长 1505 字符；官方限制：qwen-image-2.0 系列 1300 Token，其余 800 Token，超出自动截断。
- 负向总长 535 字符；官方限制 500 字符，超出自动截断。

| 层（修前顺序） | 本层字符 | 累计字符 |
|---|---:|---:|
| 画质与风格 | 103 | 103 |
| 固定人物 | 332 | 435 |
| 发型 | 34 | 469 |
| 气质与年龄 | 266 | 735 |
| 表情 | 128 | 863 |
| 服装 | 223 | 1086 |
| 构图与视角 | 189 | 1275 |

结论：按 1 字符≈1 Token，截断点落在表情/服装段，构图、光影、背景全部收不到；按 1.5 字符/Token，构图段也被从中间截断。

负向：`裁切脚部` 首次出现于第 498 字符，`脚部出画、脚尖被裁、头顶贴边、人物占满画面` 全在 500 之后。

## 2. 修后落地（当前代码）

- `PROMPT_LAYER_ORDER`：quality → character → composition → hairstyle → vibe → expression → clothing → lighting → background。
- `PROMPT_BUDGET`：正向 780、负向 480；`measurePromptChars` 按 Unicode 码点计数；`assertPromptBudget` 超限抛错。
- `buildPromptParts`：描述只吃剩余预算，返回 `descriptionTrimmed`；人物层已在风格串里时不重复前置。
- 负向合并顺序改为：`FRAMING_NEGATIVE` 在前 → 基础负向 → 尾巴负向。全身裁脚词因此在最前。
- 出图 meta 记录：`promptChars`、`descriptionTrimmed`、provider/model/tier、参考图 sha256/宽高、真实输出宽高、seed、framing/vibe/hairstyle 及其来源。

## 3. 参考图实测

- 锚点 `state/anchors/dafish-anchor.png`：832×1216（约 2:3），坐姿近景，头顶几乎贴边，下缘截在膝上，脚不在画面，人物约占画面高度 90%–95%。
- prompt 目标为站姿全身 60%–75%，出图仍跟锚点：说明参考图在"包含范围、姿势、机位、构图"四个维度上压过 prompt。
- 修复方向（按性价比排序）：
  1. 换站姿全身锚点：头顶留 8%–10%、脚底留 6%–8%、人物 65%–72%、脚完整落地、背景完整。
  2. 首句声明"参考图只提供身份与外观，不沿用其姿势、景别、机位、构图与背景"。
  3. 双图拆分：`<image1>` 空画布定构图，`<image2>` 锚点定身份。
  4. 出图后 bbox 占比检测，超 78% 或脚缺失时扩图/二次 edit。
- 扩图定量公式：`新占比 = 原占比 / (1 + 上扩比例 + 下扩比例 + 左右不影响)`；90% 人物下扩 30% ≈ 69%，下扩 25% ≈ 72%，下扩 35% ≈ 67%。

## 4. 景别词与典型占比

| 词 | 包含范围 | 典型占比 | 备注 |
|---|---|---:|---|
| `close-up` | 脸/局部 | — | 太大，不适合立绘 |
| `portrait` | 头肩 | — | 太大 |
| `upper body` | 头到腰 | 70%–85% | 半身 |
| `cowboy shot` | 头到大腿 | 70%–85% | 脚一定不在画面 |
| `full body` | 头到脚 | 80%–95% | 只保证完整，不保证不顶满 |
| `full shot` | 头到脚 + 少量环境 | 70%–85% | 更接近目标 |
| `wide shot` | 人物 + 环境 | 50%–75% | 压占比首选 |
| `long shot` / `extreme wide shot` | 人物很小 | <50% | 慎用 |

## 5. 风格单一：单值锁清单

| 维度 | 修前状态 | 位置 |
|---|---|---|
| 画风 | quality 固定"赛璐璐上色与厚涂混合" | image-gen.mjs 默认层 + config `promptLayers.quality` |
| 光影 | 固定"左前上方主光 + 冷蓝环境光 + 体积光 + 浅景深" | 同上 lighting |
| 背景 | 固定"三层纵深 + 虚化" | 同上 background |
| 机位 | 三档景别全部写死"平视" | `FRAMINGS` |
| 预设 | 5 个 `STYLE_PRESETS` 共用同一句 quality | `STYLE_PRESETS` |
| 负向 | 颗粒、噪点、平涂卡通、粗描边扁平上色、写实照片、半写实、3D渲染、背景杂乱 | `NEGATIVE_CORE` + config |

负向词反向封锁对照：

| 负向词 | 原本防什么 | 同时封死什么 |
|---|---|---|
| 颗粒、噪点 | 低质数码噪点 | 胶片颗粒、纸纹、水粉、手绘质感 |
| 平涂卡通、粗描边扁平上色 | 廉价粗边平涂 | 赛璐璐番剧风 |
| 写实照片、真人、半写实 | 真人化/BJD 娃娃感 | 轻写实、动画电影感 |
| 背景杂乱 | 元素堆叠抢主体 | 高密度叙事型背景 |
| 3D渲染、3D人偶 | 三维塑料感 | 部分厚涂/材质表达 |

## 7. 风格验收实验（本地可算）

| 指标 | 算法 | 通过标准 |
|---|---|---|
| 风格分离度 | HSV 32/16/16 直方图两两 L1 均值 | ≥ 基线 2 倍 |
| 色相覆盖 | 主色相聚类/峰值 | ≥ 4 个中心 |
| 线条强度 | Laplacian 方差 + Canny 密度 | cel_anime ≥ soft_painterly × 1.3 |
| 明度分布 | V 直方图均值与暗部占比 | 同时出现高调与低调 |
| 身份一致性 | 发色 H/S 命中 + 瞳色命中 + 鳍耳人工 1–5 分 | ≥ 基线 −0.5 分，鳍耳缺失 ≤ 1/8 |
| 盲评 | 10 人回答"是否同一种画风" | 认同率 < 40% |
| 稳定性 | 同风格同 prompt 重跑 | 风格不飘，失败率 ≤ 基线 +5pp |

实验矩阵（32 张起）：A 基线 3 张；B 八档同描述 8 张；C 三档 × 三场景 9 张；D 八档重跑 8 张；E 两档 × 有/无锚点 4 张。
